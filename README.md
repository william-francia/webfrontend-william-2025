## About

These projects were built to demonstrate my front-end development skills, focusing on clean design, responsiveness, and real user interaction.

The main project is a website for a hardware import business. It’s fully responsive and designed to provide clear and structured information in a professional layout.

The second project (Chamber) includes additional functionality like API integration and form handling.

## What I Implemented

### UI & Responsive Design

* Fully responsive layout (works on mobile, tablet, and desktop)
* Clean and modern interface
* Structured and user-friendly navigation

### API Integration

* Fetches external data (e.g., current weather)
* Displays real-time information dynamically

### User Interaction

* Join form to collect user information
* Data can be used later for contact purposes
* Membership selection includes a modal (pop-up) overlay for better user experience

These projects were created earlier in my learning journey, but they represent a strong foundation in front-end development, including layout design, responsiveness, and basic JavaScript functionality.
